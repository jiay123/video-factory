# writer · 文案

## 职责

选题 → 钩子 → 10 段脚本。每集 40-50 秒，每段 4-5 秒。

## 选题池规则

建一个 `选题池.md`，格式：

```markdown
### N. 选题名（状态）
- 钩子：
- 内容：
- 素材源：
- 可视化：
- 大众度：★★★★★
```

规则：
1. 做掉一个删一个，补一个新的，池子永远满 20
2. 同类选题隔开用（会员类 / 工具类 / 信息差类轮着来）
3. 大众共鸣度高的排前面
4. 开做前先确认素材可落地（真免费、真能用）

## 产出

1. 选题卡片（上面的格式）
2. **10 段脚本**，格式照 `examples/script.md`：每段一行，行=配音=画面

## 自检清单（交稿前过一遍）

- [ ] 开头 0-2 秒：主角 + 情绪词 + 闪亮框
- [ ] 招牌词 / 身份牌对应当集内容
- [ ] 结尾有互动钩子（扣1扣2 或「评论区扣工具」）
- [ ] 总时长 40-50 秒（10 段 × 4-5 秒）
- [ ] 每个数字有出处，「免费」亲自验证过
- [ ] 不吹牛、不标题党到失实

## 铁律

1. **不吹牛**：写「免费」前自己先跑通；写数字先找到出处
2. 同类爆款选题隔一两个月再用（防止自我重复）
3. 人设统一：爱折腾的普通人，帮观众省钱省事，不装专家
