# 脚本格式示例 · 第10集《Jev被挤爆了》

每集交稿就是这个格式：**一行 = 一段 = 一场景配音**。
producer 用 `tts.py` 按行拆分生成音频，`timing.txt` 的 start 对齐各场景粒子动画。

```text
Jev注册关门了，我却白嫖到了它的平替。
今天注册页就一句话：我们满了，别来了。
前几天说的快193倍的AI，现在门都不给进。
没事，开源平替Laya，我已经装进电脑了。
Apache 2.0协议，614兆权重，下载只要9秒。
不联网，不充钱，CPU跑一次几百毫秒。
判断、打分、选择，三类问题一次出结果。
可我拿10道答案已知的题考它，只对了一半。
快是真快，准也是真不准，先当草稿纸用。
想要这个平替的，评论区扣工具。
```

存成 `script.txt`（纯文本，每行一段），然后：

```bash
python tools/producer/tts.py --script script.txt --out src/audio
```

## 格式要求

1. **10 段**左右，每段 4-5 秒，总长 40-50 秒
2. 第 1 段 = 开头钩子：主角 + 情绪词（0-2 秒亮相）
3. 最后 1 段 = 互动钩子（扣1扣2 / 评论区扣工具）
4. 每段单独成行，行内不要换行符
5. 数字必须有出处（本集的 193倍 / 614兆 / 9秒 / Apache 2.0 均已核对）
